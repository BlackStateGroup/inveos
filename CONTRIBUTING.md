# Contributing to INVEOS

This is currently a Black State Group planning foundation with **all rights reserved** status, not an open contribution licence. Seek maintainer permission before submitting proprietary or third-party code. For implementation contributions, open an issue and include original authorship, third-party dependency/SBOM changes, licence analysis, tests, relevant UI states and privacy/security impact. No real people or operational client data in examples. No claim that a vulnerability test, audit, integration or deployment passed unless it actually ran.
