# 20 — Competitor landscape and adjacent tools

The goal is **not** to clone a competitor's protected UX or proprietary code. Use publicly visible capability categories and customer feedback to discover missing workflows; develop original INVEOS implementations.

| Product / project | What to study | Gap or different market angle |
|---|---|---|
| CROSStrax | Investigator agency case handling, assignments, time/billing, reports | Validate opportunities in mobile capture → evidence-to-report lineage |
| Trackops | Case operations, billing, client communication, automation/AI features | Avoid claiming AI case admin is novel; verify current offering and pricing |
| DFIR-IRIS | Incident investigation case and task collaboration | Cyber incident response focus; LGPL licence and domain mismatch |
| TheHive | Incident response case workflows and operational collaboration | Archived open-source repo and commercial distribution; not a copy target |
| OpenCTI | Knowledge graph, source provenance and intelligence objects | Threat intelligence domain; complex deployment and licence review |
| OpenAleph / Aleph | Large-scale document indexing and entity research | Strong model/UX research for corporate documents |
| Timesketch / Plaso | Event timelines and ingest of multi-format forensics | Specialist forensic tooling; useful import/reference, not core product |
| OpenOSINT / SpiderFoot | Modular passive collection adapters | Tool purpose, external API/ToS and personal privacy constraints matter |
| ODK Collect | Offline field forms, resume and sync patterns | Generic survey collection; INVEOS needs original media and custody |
| forenix-oss | Source capture plus traceability/chain-of-custody pattern | Experimental upstream; evaluate rigorously, never assume evidence-grade claims |

## Research rules

- Use official product documentation and public demos; do not reproduce screenshots/art unless licensed.
- Record product capabilities as dated observations and do not extrapolate from marketing claims.
- Ask real investigators about time spent, case import barriers, evidence export and client privacy.
- Test comparative workflows with a **fictional** standard case, not customer files.
