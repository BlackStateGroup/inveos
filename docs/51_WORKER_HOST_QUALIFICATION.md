# Worker host qualification

This first-party probe is a prerequisite experiment for WP-05, not a parser benchmark or permission to ship dependencies. Local Docker is absent; unsupported hosts fail closed. On the disposable CI host it reuses the already-present PostgreSQL test image, replaces its entrypoint with first-party shell checks and never starts another database, pulls an image or executes a document parser. The image tag is resolved once to its immutable local image ID, which is recorded in the receipt. This convenience image is not selected or licensed as the future parser runtime.

Run `python3 tools/probe_worker_isolation.py --image postgres:15` on a supported Docker host after its existing test image is present. CI bounds the whole command to 90 seconds. The probe creates random named containers with UID/GID 65534, no network, no capabilities, no new privileges, read-only root and original, bounded noexec scratch, 0.5 CPU, 128 MiB RAM/swap total and 32 PIDs. Only a fictional original and empty output directory are host-mounted. No host credentials, repository or Docker socket is passed into the container. Temporary output is not trusted application evidence.

It checks actual denial of original/root writes and host-loopback access (against a confirmed listener), absence of a default route and Docker socket, zero effective capabilities, no-new-privileges, cgroup-visible limits, successful separate output, scratch exhaustion, original hash preservation and forced removal after a wall-time expiry. CPU/RAM/PID caps are inspected, not stress-tested to exhaustion. It does not claim resistance to kernel exploits, malicious PDFs, complete egress analysis, production tenancy or a safe arbitrary parser executor. Python policy tests deliberately weaken settings and require rejection; those tests alone do not prove isolation.

All containers and anonymous volumes are removed even on probe failure. There is no application/schema change; rollback removes the CI step, probe and tests. Before parsing: select minimal runtime artifacts, resolve hashes/SBOM/notices and vulnerability review, rerun and strengthen these checks with that exact image, restrict all image-defined writable volumes, bound output/pages/archive expansion and test malformed/partial results. Docling/Tika/OCRmyPDF remain unexecuted and unapproved for incorporation.
