# Reviewed transcript interpretation and report lineage

**Active implementation, not yet acceptance-tested or merged.** Fictional supplied transcripts only. This batch follows the Field/team/entity work in #96 and must integrate its final validated merge.

The server now implements source-linked transcript proposals, immutable independent decisions, separate findings and explicit withdrawal. Each proposal retains its original identity/policy, raw source segment, ordered corrections through the selected version, source JSON pointer, exact quotation offsets in that version's UTF-8 text, declared speaker/time uncertainty and actor/time/digest. It cannot claim audio alignment or source truth. A proposal author or correction author cannot independently accept that interpretation. Later corrections/authority changes make acceptance stale. A reviewer can withdraw an accepted interpretation without erasing its records; new report generation omits explicitly withdrawn findings and refuses stale unwithdrawn ones.

The Interview interface is connected to proposals, citation inspection, review and withdrawal. Report generation/frozen-source checking, print rendering, deterministic PDF/redaction and independent Python report/document-package verification are being extended in this same batch. Transcript findings embed exact original bytes and correction lineage; the standalone verifier checks them rather than treating rehashed fields as proof. Source assertions remain separate from reviewed interpretations. Version 2 of the offline exhibit manifest adds transcript references while preserving version 1 outputs for legacy text-only reports.
