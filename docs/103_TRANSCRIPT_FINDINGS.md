The server now implements source-linked transcript proposals, immutable independent decisions, separate findings and explicit withdrawal. Each proposal retains its original identity/policy, raw source segment, ordered corrections through the selected version, source JSON pointer, exact quotation offsets in that version's UTF-8 text, declared speaker/time uncertainty and actor/time/digest. It cannot claim audio alignment or source truth. A proposal author or correction author cannot independently accept that interpretation. Later corrections/authority changes make acceptance stale. A reviewer can withdraw an accepted interpretation without erasing its records; new report generation omits explicitly withdrawn findings and refuses stale unwithdrawn ones.

The Interview interface is connected to proposals, citation inspection, review and withdrawal. Report generation/frozen-source checking, print rendering, deterministic PDF/redaction and independent Python report/document-package verification are being extended in this same batch.
